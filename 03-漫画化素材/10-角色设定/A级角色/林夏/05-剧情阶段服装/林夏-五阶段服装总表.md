# 林夏五阶段服装总表

## 文档目的

- 在不换脸、不换体态语言的前提下，推进林夏的剧情阶段服装
- 让林夏从 `基础造型` 进入 `阶段化造型`
- 为后续第 01 集场景试制和分镜使用提供稳定服装锚点

## 执行前提

本表默认继承以下既有锚点：

- `01-脸部身份确认/林夏-脸部设定-提示词-V2.md`
- `03-体态与基础造型/林夏-体态与基础造型-提示词-V1.md`

所有阶段服装都必须满足：

- 还是同一张脸
- 还是同一种肩颈关系和重心
- 还是“克制、内压、判断感”的动作语言
- 服装变化来自处境变化，不来自角色重设计

## 五阶段顺序

### 1. 联邦意识雕刻师阶段

- 阶段定位：系统内部的高精度执行者
- 关键词：洁净、冷静、低噪音、职业判断感
- 服装方向：
  - 冷灰、灰蓝、冷白
  - 结构精确，干净贴身但不时装化
  - 少量专业功能缝线或接口感
  - 不做权力制服感，不做未来高定感

### 2. 逃离后的过渡阶段

- 阶段定位：还带着联邦痕迹，但已进入失稳与移动期
- 关键词：未脱净、转换中、克制防护、半脱系统
- 服装方向：
  - 保留联邦底层内搭
  - 外层开始增加现实世界的轻功能件
  - 材质开始出现轻微磨损、折痕和防护逻辑
  - 不做狼狈逃难感，不做废土英雄感

### 3. 修补者现实行动阶段

- 阶段定位：正式进入现实世界工作与行动
- 关键词：实用、轻行动、低调、可靠
- 服装方向：
  - 更适合移动、潜入、维修和短时对抗环境
  - 比联邦阶段更有层次，但仍然整洁
  - 增加现实功能口袋、耐磨外层和简洁靴装
  - 不走重战术，不走拾荒拼装

### 4. 裂缝 / 内核行动阶段

- 阶段定位：进入高压、高判断、高风险真相区
- 关键词：聚焦、削减、判断者、去装饰
- 服装方向：
  - 进一步压低装饰和层次
  - 结构更简洁、更收束
  - 强调稳定、耐用、便于在异常环境行动
  - 不能做成科幻战斗服，也不能做成精神领袖装

### 5. 守桥阶段

- 阶段定位：现实与网络之间的新秩序承接者
- 关键词：中间质感、稳定、耐看、非权力化
- 服装方向：
  - 联邦精确感与现实功能感融合
  - 材质要更平静、更长期可穿
  - 轮廓简洁，像桥梁而不是王座
  - 不做神性化、领袖化、圣像化

## 跨阶段不变项

以下特征在五个阶段都不能漂：

1. 脸部骨相和发髻结构
2. 偏瘦、利落、内收的身形比例
3. 肩略收、颈稳定、重心稳的体态
4. 不外放、不张扬的动作语言
5. 干净、克制、判断先于表现的气质

## 允许变化项

以下内容可以随阶段变化：

1. 外层服装结构
2. 材质磨损程度
3. 联邦感与现实感的比例
4. 功能件数量
5. 色彩深浅与层次密度

## 阶段间的变化逻辑

正确变化应表现为：

`联邦精确 -> 半脱系统 -> 现实行动 -> 高压收束 -> 桥梁融合`

错误变化包括：

- 越往后越像战斗女主
- 越往后越像废土战士
- 越往后越像未来领袖圣像
- 每个阶段都像换了一个角色

## 推荐生成顺序

1. 联邦意识雕刻师阶段
2. 修补者现实行动阶段
3. 守桥阶段
4. 逃离后的过渡阶段
5. 裂缝 / 内核行动阶段

这个顺序的目的不是按剧情时间线，而是先锁：

- 起点
- 现实常用态
- 终点

然后再补中间两段过渡。

## 当前结论

- 林夏五阶段服装的核心不是“换造型”，而是“同一人物在不同处境中的连续变化”
- 每一阶段都必须继续服务林夏的主视角身份
- 后续生成时，应优先比较五阶段之间是否仍然是一人，而不是单独判断某一张是否好看
