# 林夏光效适配完整提示词

## 目标

验证林夏进入参考页那种空间后会不会跑风格。重点测试两套环境：

- 无尽网络冷白青蓝 UI 光效
- 现实世界低照度冷灰环境

## 统一角色锚点

- 沿用已转译完成的漫画写实林夏脸
- 判断型眼神
- 冷静、克制、理性
- 同一张脸在不同光环境下都稳定

## 统一风格要求

- 中文科幻条漫镜头
- 半身中近景
- 人脸结构在环境光下仍然清楚
- 留出一定对白区或阅读安全区

## 推荐尺寸与分辨率

- E1 推荐竖版环境镜头：`4:5`
- E2 推荐竖版环境镜头：`4:5`
- 测试分辨率建议：
  - `1024 x 1280`
  - 或 `1536 x 1920`
- 光效测试时建议关闭平台自带的“过强柔光美颜”倾向

## 统一禁止项

- 不要科技广告感
- 不要霓虹秀场
- 不要发光洗脸
- 不要影视剧照感
- 不要过暗不可读

## E1 无尽网络冷白青蓝 UI 光效半身图

林夏，半身中近景，竖版4:5，高细节，建议1024x1280或1536x1920，无尽网络环境，冷白青蓝雾蓝UI光效，半透明界面，漫画写实脸，判断型眼神，联邦专业感，人物结构在发光环境下仍清楚，中文科幻条漫镜头，不要科技广告，不要霓虹秀场，不要发光洗脸

## E2 现实世界低照度冷灰环境半身图

林夏，半身中近景，竖版4:5，高细节，建议1024x1280或1536x1920，现实世界低照度冷灰环境，漫画写实脸，判断型眼神，现实行动态服装，旧金属与工作灯气氛，人物可读但环境更重，中文科幻条漫镜头，不要影视剧照感，不要过暗，不要和无尽网络一样顺滑
