# `50-漫画试制管理` 目录说明

本目录只处理“当前漫画试制推进”相关文件。

## 当前使用顺序

- `00-当前执行入口/`
  - 当前阶段真正需要直接打开的入口
- `10-角色复审与修正/`
  - 角色复审标准、复审记录、定向修正任务
- `20-场景试制/`
  - 当前场景卡与场景试制规划
- `90-过程归档/`
  - 已完成阶段的规划稿、心得稿、快速复审稿

## 当前建议入口

1. 先看 `00-当前执行入口/28-核心角色漫改优先执行计划.md`
2. 再看 `00-当前执行入口/27-第01集试制前执行清单.md`
3. 需要查角色状态时，看 `00-当前执行入口/21-AI漫画角色素材进度表.md`
4. 需要回看角色判断标准时，再进入 `10-角色复审与修正/`
5. 准备切场景时，再看 `20-场景试制/22-第01集漫画试制场景卡.md`

## 整理原则

- 主目录不再堆放阶段过程稿
- 当前入口优先于历史过程
- 有判断价值但已过阶段的文件不删除，统一放入 `90-过程归档/`
