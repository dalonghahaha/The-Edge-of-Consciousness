# 《意识的边疆》全角色统一风格控制总表

## 文档目的

- 用于统一《意识的边疆》所有角色在 AI 生成中的风格口径
- 用于避免“单个角色局部好看，但全项目放在一起像不同作品”的问题
- 用于把角色一致性控制从“凭感觉”变成可重复执行的生产流程

## 适用范围

- `03-漫画化素材/10-角色设定/` 下所有角色图
- 后续 `20-场景设定/`、`30-分集试制/` 中所有带人物出镜的测试图
- 当前优先适用于：
  - 林夏
  - 老汤姆
  - 零
  - 艾娃
  - 陈博士
  - 小丑
  - 清道夫

## 总原则

### 1. 先统一作品风格，再统一角色

角色不能各自寻找“最适合自己的画风”。

必须先确认：

- 这部漫画整体长什么样
- 哪些视觉特征是全项目统一的
- 哪些特征只允许作为角色差异存在

### 2. 风格统一不等于人物变像

统一的是：

- 线条逻辑
- 阴影逻辑
- 上色逻辑
- 光效逻辑
- 镜头语言
- 构图节奏

不能统一的是：

- 脸型
- 骨相
- 站姿
- 阵营气质
- 人物功能

### 3. 角色一致性优先级高于单张惊艳

允许放弃局部“更炸裂”的图，换取：

- 全角色放在一起是同一部作品
- 同一角色跨场景还是同一人
- 同一场景内镜头切换不跳风格

## 第一层：全项目统一风格母版

这是所有角色都必须继承的最高级风格控制。

### 必须统一的风格母版要素

#### A. 线条

- 人物外轮廓必须清楚
- 五官、下颌、鼻梁、发际线、领口等关键识别边界必须稳定
- 不走二次元夸张黑线，也不走纯厚涂无边界
- 推荐方向：`漫画写实 + 清晰轮廓线 + 受控的结构线`

#### B. 阴影

- 阴影要有分区逻辑，不能全靠照片式光影自然坍缩
- 面部阴影优先服务识别，不优先服务摄影感
- 眼窝、鼻梁、嘴角、下颌、颈肩必须有稳定阴影语言
- 推荐方向：`稳定阴影分区，而不是随机写实明暗`

#### C. 色彩

- 全项目统一采用低饱和冷灰体系作为人物基底
- 人物肤色不做广告式发光白皮
- 环境色差异来自世界层级，不来自角色乱漂
- 推荐方向：
  - 现实世界：冷灰、深灰、脏白、旧金属色
  - 无尽网络：冷白、雾蓝、青蓝、柔和浅冷光
  - 裂缝真相区：冷黑、异常白、残影青、局部错误红

#### D. 光效

- 光效必须服务世界层级，不服务花哨感
- UI 发光不能洗平脸部结构
- 现实世界不能被打成平顺广告光
- 推荐方向：`人物结构永远优先于光效奇观`

#### E. 镜头语言

- 大部分角色镜头采用可读、稳定、克制的条漫分镜语言
- 对话镜头重中近景
- 情绪镜头重特写
- 世界说明依靠人物 + 空间 + UI 共担，不靠堆台词
- 推荐方向：`稳定叙事 60%，情绪压迫 25%，异常爆发 15%`

### 全项目统一禁止项

- 不要照片棚拍感
- 不要影视剧剧照感
- 不要未来时装广告感
- 不要高饱和赛博霓虹秀场
- 不要二次元萌化
- 不要角色各自采用不同画法

## 第二层：角色锚点控制链

每个角色都必须按统一控制链推进，不允许跳步骤直出成页。

### 标准控制链

1. `01-脸部身份确认`
2. `02-面部全视角`
3. `03-体态与基础造型`
4. `05-剧情阶段服装`
5. `06-漫画化风格转译`
6. `30-分集试制` 中的单格 / 分镜 / 成页验证

### 控制链规则

- 后一步默认继承前一步已确认版本
- 未锁定 `01` 的角色，禁止进入 `06`
- 未锁定 `03` 的角色，禁止大规模做全身单格和分镜页
- 未锁定 `05` 的主角色，禁止进入高频剧情成页测试

### 统一执行口径

当说“执行某个角色”时，默认不是随机生几张图，而是：

- 继承该角色最近一次确认版本
- 继承全项目风格母版
- 继承当前世界层级的色彩与光线规则

## 第三层：统一提示词骨架

所有角色提示词都必须共用同一套骨架，只替换角色变量。

### 固定字段

每张图都应明确包含：

1. 角色身份
2. 脸部锚点
3. 体态锚点
4. 镜头类型
5. 服装阶段
6. 世界层级 / 环境类型
7. 线条要求
8. 阴影要求
9. 色彩要求
10. 输出比例与分辨率
11. 统一禁止项

### 允许变化的字段

- 角色名
- 年龄与性别
- 骨相和面部关键词
- 体态与轮廓关键词
- 阶段服装逻辑
- 当前镜头任务
- 当前空间系统

### 不允许自由漂移的字段

- 画风关键词
- 阴影关键词
- 色彩底层口径
- 条漫成页可读性要求
- 禁止项

## 第四层：统一尺寸与输出规则

后续所有角色按镜头类型统一尺寸，不再随手出图。

### 角色脸部设定页

- 用途：`01 / 02`
- 推荐比例：`3:2`
- 推荐分辨率：
  - `1536 x 1024`
  - 或 `2048 x 1365`

### 半身对白 / 半身环境镜头

- 用途：`06` 中对白测试、光效测试
- 推荐比例：`4:5`
- 推荐分辨率：
  - `1024 x 1280`
  - 或 `1536 x 1920`

### 情绪特写

- 用途：近景心理镜头
- 推荐比例：`4:5`
- 推荐分辨率：
  - `1024 x 1280`
  - 或 `1536 x 1920`

### 全身执行造型

- 用途：基础造型 / 阶段服装全身图
- 推荐比例：`3:4`
- 推荐分辨率：
  - `1024 x 1365`
  - 或 `1536 x 2048`

### 成页单格模拟

- 用途：分镜前条漫单格测试
- 推荐比例：`9:16`
- 推荐分辨率：
  - `1024 x 1792`
  - 或 `1152 x 2048`

## 第五层：模型与参考图控制

### 统一规则

- 同一轮角色生产，尽量固定同一主模型
- 同一角色的连续测试，尽量固定相近参数
- 有条件时，固定：
  - 同一参考图
  - 同一角色参考强度
  - 同一 seed 逻辑

### 参考图使用规则

参考图分两类，不得混用逻辑：

#### A. 风格母版参考图

用于统一“这部作品长什么样”。

要求：

- 3 到 8 张
- 必须来自你最终认可的项目风格方向
- 覆盖：
  - 近景脸
  - 半身对白
  - 全身
  - UI 光效
  - 现实世界
  - 无尽网络

#### B. 角色锚点参考图

用于统一“这个角色长什么样”。

要求：

- 优先使用该角色已确认的 `01 / 02 / 03 / 05 / 06` 结果
- 后续镜头图都必须继承前序确认稿

### 结论

上传旧图给模型或给我看，是必要帮助，但不是充分条件。

真正稳定统一靠的是：

- 风格母版固定
- 角色锚点固定
- 提示词骨架固定
- 输出规格固定
- 结果筛选固定

## 第六层：筛图与准入标准

所有角色图都必须过筛，不合格即淘汰，不因“局部好看”保留。

### 必筛 8 项

#### 1. 同人稳定度

- 这张图是否仍然是同一个角色

#### 2. 角色准确度

- 这张图是否仍然是“这个角色”，而不是被 AI 拉成流行模板

#### 3. 风格统一度

- 这张图和其他角色放在一起，是否像同一部漫画

#### 4. 镜头可读性

- 缩小到条漫单格后，脸、眼神、嘴角、动作是否仍可读

#### 5. 世界层级准确度

- 现实世界、无尽网络、裂缝区是否仍然一眼可分

#### 6. 光效克制度

- 光效是否服务人物和空间，而不是压过人物

#### 7. AI 模板化风险

- 是否被拉向：
  - 精英模板
  - 漂亮模板
  - 冷酷反派模板
  - 时装模板

#### 8. 连画可复用性

- 这张图是否适合后续继续被当作角色参考，而不只是一次性漂亮图

### 准入分级

#### `通过`

- 可进入下一阶段

#### `观察通过`

- 可保留，但必须带风险备注继续测试

#### `淘汰`

- 不纳入后续角色参考链

## 当前执行顺序建议

### 第一批：先锁 7 个 A 级角色的统一风格转译

顺序建议：

1. 林夏
2. 老汤姆
3. 清道夫
4. 零
5. 陈博士
6. 艾娃
7. 小丑

原因：

- 林夏是主视角和风格母线
- 老汤姆、清道夫能先锁现实与制度执行两端
- 其余四个模板化风险更高，需要在母线稳定后修正

### 第二批：建立全项目风格母版图组

从现有林夏试制图和后续老汤姆 / 清道夫 / 零等角色中，筛出一批项目统一参考图。

### 第三批：再进入分集试制

角色统一风格链没有锁稳前，不建议大规模推进分镜和成页。

## 当前结论

- 全角色风格统一不能靠临时记忆和主观印象
- 也不能只靠“把旧图发给模型看看”
- 必须通过：
  - 统一风格母版
  - 统一角色控制链
  - 统一提示词骨架
  - 统一尺寸规格
  - 统一筛图标准

后续所有角色图，统一按本表执行。
